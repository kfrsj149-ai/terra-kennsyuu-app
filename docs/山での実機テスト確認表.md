# 山での実機テスト確認表

使い方：1つずつ試して、結果を「OK」か「NG（どうなったか）」で記録する。NGだけ報告すればよい。
開くURL：https://terra-kennsyuu-app.vercel.app/ （ホーム画面のアイコンは、追加し直す）

## A. 起動とホーム画面
1. ホーム画面に追加して開く → 全画面で開く
2. 起動してから2〜3秒のあいだ、下のボタン（直前取消・データ出力）が**一瞬隠れない**
3. 画面を横にして縦に戻す → ボタンが隠れない
4. 他のアプリに切り替えて戻る → ボタンが隠れない

## B. 圏外
5. 機内モードにして開く → 真っ白にならず、計測できる
6. 圏外で10本入れる → 本数と材積が合う
7. 音声入力のボタンが、グレーで、案内が出る

## C. 炎天下・手袋
8. 日向で画面が読める（数字・ボタン）
9. 径級カードを押すと、**押した直後だけ濃くなり、すぐ元の色に戻る**（光る・震える・音の4つがある）
10. 手袋でタップできる（押し間違いが多くない）
11. カードの長押し（2秒）で1本減る
12. 直前取消で、取り消した行が「薄い灰色＋赤の取り消し線」で残る

## D. 出力
13. データ出力 →「はい」→ 共有画面が出て、LINEに送れる
14. 出力確認の「端末に保存」→ ファイルが保存される（保存場所を覚えておく）
15. 出力確認の「紙伝票の形で見る」→ 紙に書き写しやすい（文字の大きさ、黄色の行）
16. メニューの「ホームへ戻る」→ 確認が出る →「戻る」で計測に残る →「はい」で準備画面に戻る

## E. 帰ってから（山ではできない）
17. 「手書き伝票を印刷」→ A4で印刷して、枠・文字が読める
