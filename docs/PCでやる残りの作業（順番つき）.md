## A．まず（約20分）：お客さんが使うために必要なもの

### A-1 カスタマーポータルの設定（約5分）
お客さんが、アプリの「支払い・プラン管理」を押したときに開く画面です。**本番で保存していないと、そのボタンが動きません。**（2026-11-18 の時点で、本番は未保存）
1. `https://dashboard.stripe.com/settings/billing/portal` を開く。左上が「TERRA」（本番）であることを確認
2. 「ビジネス情報」に入れる
   - 利用規約：`https://log-ra.terra-tx-jp.com/legal/terms/`
   - プライバシーポリシー：`https://log-ra.terra-tx-jp.com/legal/privacy/`
3. 「顧客ができること」：支払い方法の更新＝オン／請求書の履歴＝オン／サブスクリプションの解約＝オン（「請求期間の終了時」）／数量（台数）の変更＝オフ
4. 「変更を保存」
- **確認**：Claude に「保存した」と伝える（Claude が Stripe から読み取って確認する）
- 注意：同じ Stripe アカウントを使う他のアプリ（日報など）と、この設定は共通。日報が有料になる前に、アプリごとに分ける方法を決める

### A-2 通常価格の購入リンクを作る（約10分。期限：**2026-12-31**）
2027年1月1日から使うリンクです。作り忘れると、年明けから購入ボタンが「準備中」になります。
1. `https://dashboard.stripe.com/payment-links/create` を開く
2. 商品は、価格に「**通常価格**」と出ているほうを選ぶ（商品名が同じものが複数ある。「(Copy)」は選ばない）
3. 「顧客が数量を調整できるようにする」にチェック。最小 `1`、最大 `99`
4. 「オプション」：「ビジネス名を収集」にチェック／「プロモーションコードを許可」にチェック／「Managed Payments」はオフ
5. 「支払い完了ページ」のタブ → 「確認ページを表示しない」→ 次のURLを貼る
   `https://log-ra.terra-tx-jp.com/?checkout=success&session_id={CHECKOUT_SESSION_ID}`
6. 「リンクを作成」→ できた `https://buy.stripe.com/…` のURLを、Claude に貼る（購入ページの住所なので、貼ってよい）
- **確認**：Claude が Stripe から設定を読み取って確認し、アプリの `config.js` に入れて公開する

### A-3 使わないプロモーションコードを無効にする（約2分）
Stripe が、作成の途中で自動で作ってしまったコード（使わないもの）が1つ残っています。
1. `https://dashboard.stripe.com/coupons` → いまのクーポンを開く → 「プロモーションコード」の一覧
2. **自動で作られた文字列のほう**の「…」→ 無効にする（しんたろうさんが決めた合言葉のほうは、使用済みなので、そのままでよい）
- **確認**：一覧で、無効になっている

1. 確認用 `https://log-ra.terra-tx-jp.com/lp/log-ra/` をスマホで見て、直したい所を Claude に伝える

- **注意**：`firebase deploy` は `public` フォルダ全体で本番を置き換える。別フォルダで実行しない（NIPPO-RA と同じ `public` を使う）

## C．あとでよい（急ぎではありません）

### C-1 インボイス登録番号の確認（**2026-11-24：登録番号は「なし」と確認。Stripe 側の設定は不要**）
本番の請求書で、消費税が「徴収していない」扱いでした。お客さん（法人）が、インボイスを求めるときのために、確認が要ります。
1. しんたろうさんが、**適格請求書発行事業者の登録番号（T＋13桁）を持っているか**を確認（持っていなければ、Stripe 側の設定は不要。請求書は、その旨のまま）
2. 持っているときは、Stripe の「設定」→「税」→「登録」に、国内の登録を追加し、登録番号を入れる
- 決める人：しんたろうさん（税理士に確認するのがおすすめ）

### C-2 事務所コードの再発行（**不要になりました**）
以前、テスト環境の事務所コードを、スクリーンショットで見せたことがありました。2026-11-13 に、Stripe の鍵を本番に替えたので、**テストのときの契約は使えなくなり、そのコードでは、もう入れません。**
- 本番で事務所を使い始めるときは、新しく初期設定をする（コードは新しく作られる）。そのとき表示された事務所コードは、**写真に撮らず、パスワード管理アプリに保存**する
- もし、本番で作った事務所コードを人に見せてしまったら：事務所の画面「設定」→「事務所コードを作り直す」

### C-3 `OPERATOR_KEY`（運営者コンソール `/ops/` を使うときだけ）
1. ランダムな長い文字列を作る。Windows の PowerShell で、次の3行を実行して、出た文字列をコピー
   `$b = New-Object byte[] 32`
   `[Security.Cryptography.RandomNumberGenerator]::Create().GetBytes($b)`
   `[Convert]::ToBase64String($b)`
2. Vercel（log-ra）の「Settings」→「Environment Variables」→ 名前 `OPERATOR_KEY`、値に貼る。「Sensitive」をオン
3. 再デプロイ（Deployments → 最新 → 「…」→ Redeploy）
4. `https://log-ra.terra-tx-jp.com/ops/` を開き、その文字列でログイン
- 鍵は**全社のデータを見られる合鍵**。パスワード管理アプリにだけ保存する
