# ドメイン設定の手順書（アプリを自前の住所に移す／QR用の短い住所を作る）

目的：アプリを `kennsyuu.terra-tx-jp.com` に移し、紙のQR用に `q.terra-tx-jp.com` を作る。
所要の目安：あわせて約1時間（DNSが反映されるまでの待ちを含む）。
画面の名前や位置は、VercelやCloudflareの更新で少し変わることがあります。違っていたら、その画面のスクリーンショットをClaudeに貼ってください。

**先に知っておくこと**
- 既存の `https://terra-kennsyuu-app.vercel.app/` は、そのまま使えます（消えません）。
- アプリの住所を変えると、ホーム画面に追加したアプリと端末内のデータ（下書き・伝票履歴）は引き継がれません。新しい住所で開き直して、ホーム画面に追加し直してください。いまはテスト段階なので、早く移すほど影響が小さい。
- `terra-tx-jp.com` の `/scorer/`、`/jitsugi/`、メール転送には触りません。足すのは、サブドメイン（`kennsyuu` と `q`）のレコードだけです。
- **本番決済（Stripe）の設定は、この移行のあとにしてください。** 決済リンクの戻り先URLに、新しい住所を入れるためです。

---

## 手順0：ドメインの登録事業者と更新期限を確認する（約10分）
更新を忘れると、印刷したQRが全部読めなくなります。

1. Cloudflare（https://dash.cloudflare.com）にログインする。
2. 左メニューの「ドメイン登録」（または「Domain Registration」）→「ドメインを管理」を開く。
   - `terra-tx-jp.com` が出る → Cloudflareで登録している。「更新日」と「自動更新」を確認する。
   - 出ない → 別の会社（お名前.com、ムームードメインなど）で登録している。次へ。
3. 別の会社の場合：https://lookup.icann.org を開き、`terra-tx-jp.com` を入れて検索する。「Registrar」（登録事業者）と「Registry Expiry Date」（更新期限）が出る。
4. その会社にログインして、**自動更新をオン**にし、支払い方法（カードの有効期限）を確認する。
5. Claudeに伝えるのは、**登録事業者の名前と更新期限の日付だけ**。ログイン情報は書かない。

## 手順1：アプリを `kennsyuu.terra-tx-jp.com` に移す（約20分）
### 1-1 Vercelに住所を足す
1. https://vercel.com にログインし、このプロジェクト（terra-kennsyuu-app）を開く。
2. 上のメニュー「Settings」→ 左メニュー「Domains」を開く。
3. 入力欄に `kennsyuu.terra-tx-jp.com` と入れて「Add」を押す。
4. 「Production」にひもづける選択肢が出たら、そのまま進む。
5. 赤字で「Invalid Configuration」と出て、**CNAME**の設定値（Name と Value）が表示される。この値をメモする（次で使う）。

### 1-2 CloudflareにCNAMEを足す
1. Cloudflareで `terra-tx-jp.com` を開き、左メニュー「DNS」→「レコード」を開く。
2. 「レコードを追加」を押し、次のとおり入れる。
   - タイプ：**CNAME**
   - 名前：`kennsyuu`
   - ターゲット：Vercelに表示された値
   - プロキシ状態：**DNSのみ**（灰色の雲）。オレンジの雲だとVercelの証明書が取れないことがあります。
3. 保存する。

### 1-3 反映を待って確認する
1. Vercelの「Domains」画面に戻る。数分〜数十分で「Valid Configuration」に変わる（「Refresh」で更新）。
2. ブラウザで `https://kennsyuu.terra-tx-jp.com/` を開き、アプリが出ることを確認する。
3. `https://kennsyuu.terra-tx-jp.com/office/` も開けることを確認する。

### 1-4 端末を移す
1. スマホで `https://kennsyuu.terra-tx-jp.com/` を開き、「ホーム画面に追加」し直す。
2. 古いアイコン（vercel.app 版）は、消してよい。

## 手順2：QR用の短い住所 `q.terra-tx-jp.com` を作る（約15分）
QRに入るのは `q.terra-tx-jp.com/…` だけにして、アプリ本体の住所は変えられる状態にするための手順です。**紙を印刷する前までに**やってください。

### 2-1 ダミーのDNSレコードを足す
1. Cloudflareの「DNS」→「レコード」→「レコードを追加」。
2. タイプ：**AAAA** ／ 名前：`q` ／ IPv6アドレス：`100::` ／ プロキシ状態：**プロキシ済み**（オレンジの雲）。
3. 保存する。（転送だけに使う印のレコードで、実際のサーバーはありません）

### 2-2 転送ルールを作る
1. 左メニュー「ルール」→「リダイレクトルール」→「ルールを作成」。
2. ルール名：`QR転送`。
3. 「受信リクエストが一致する場合」→「カスタムフィルター式」を選び、「式を編集」を押して、次を入れる。
   `(http.host eq "q.terra-tx-jp.com")`
4. 「その後」→ 種類「動的」→ 式に次を入れる。
   `concat("https://kennsyuu.terra-tx-jp.com/s", http.request.uri.path)`
5. ステータスコード：**302**（一時転送。あとで転送先を変えられるように、301にしない）。
6. 「クエリ文字列を保持」にチェックを入れる。
7. 保存（デプロイ）する。

### 2-3 確認
`https://q.terra-tx-jp.com/test` を開くと、`https://kennsyuu.terra-tx-jp.com/s/test` に切り替わる（まだ画面は空でよい。転送されれば成功）。

## 手順3：Claudeに知らせる
次の3点を伝えてください。
1. 登録事業者の名前と、更新期限の日付
2. `https://kennsyuu.terra-tx-jp.com/` が開けたか
3. `https://q.terra-tx-jp.com/test` が転送されたか

Claudeがやること：
- docs・READMEの住所を新しいものに直す
- 手順書の決済リンクの戻り先URLを `https://kennsyuu.terra-tx-jp.com/?checkout=success&session_id={CHECKOUT_SESSION_ID}` に直す
- terra-common の `infra/ドメインとメール.md` を更新する（住所の表と、QR用の短い住所）
- `/s/<ID>` の受け口の作成（手書き伝票のQRの行き先）

## 注意（してはいけないこと）
- Cloudflareの `terra-tx-jp.com`（ドメイン直下）のAレコード、`MX`、`TXT` は**変更・削除しない**。メール転送と `/scorer/`・`/jitsugi/` が止まります。
- 転送ルールを301にしない。
