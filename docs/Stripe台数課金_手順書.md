# Stripe 台数課金 手順書（パソコンで作業する日用・下書き）

価格の決定（2026-10-22）を、Stripe に載せるための手順です。**まずテストモードで全部通してから、本番で同じ作業をします。**
画面の表記は変わることがあります。わからなくなったら、その画面のスクリーンショットを Claude に貼ってください。

> この手順書は、`売り込み前の宿題_手順書.md` の「1-2 本番で商品を作る」の**代わり**です（価格が一律9,800円ではなくなったため）。1-1（本番の有効化）や 1-4 以降（購入リンクの戻り先など）は、そのまま使えます。

## 決めてあること（再確認しない）
- 1台目 9,800円 ／ 2台目から1台ごとに 7,500円 ／ 合計 150,000円が上限（すべて税込・年額）
- 2026-12-31 までの申込は、**初年度だけ** 2台目から 5,000円（1台目は 9,800円のまま）。更新後は通常の価格
- 台数は頭（トラクタ・トラック）の数。トレーラーと人数は数えない

## 1. 価格を2つ作る（テストモード）
Stripe の「段階制の価格」（Graduated）を使うと、「1台目だけ高く、2台目から安く、上限まで」を1つの価格で表せます。

**価格A：通常**（商品名 `LOG-RA 年額プラン`）

| 数量（台） | 1台あたり |
|---|---|
| 1 | 9,800円 |
| 2 〜 19 | 7,500円 |
| 20 | 5,200円 |
| 21 〜 | 0円 |

→ 19台 = 144,800円、20台 = 150,000円、21台以上も 150,000円（上限）。

**価格B：初年度の特典**（同じ商品の別の価格。名前に `初年度特典` と入れる）

| 数量（台） | 1台あたり |
|---|---|
| 1 | 9,800円 |
| 2 〜 29 | 5,000円 |
| 30 | 5,200円 |
| 31 〜 | 0円 |

設定：「定期支払い」→ 期間「年次」／ 通貨 JPY ／ 請求モデル「段階制」→ 「段階的」（graduated）／ 税は「税込」。

## 2. 購入リンク（Payment Link）を作る
1. 決済リンク →「新規」。価格B（初年度特典）を選ぶ（**2026-12-31 まで使うリンク**）
2. 「数量の調整を許可」をオンにする（最小 1、最大は 99 など）
3. 確認ページのリダイレクト先：`https://log-ra.terra-tx-jp.com/?checkout=success&session_id={CHECKOUT_SESSION_ID}`
4. 「プロモーションコードの使用を許可する」もオンにする（神田さん用の無期限コードのため）
5. **テストカードで、1台・3台・20台・21台を買ってみて、金額が上の表と一致するか確認する**（3台＝19,800円、20台＝104,800円）
6. 2027-01-01 からは、同じ作業を価格A（通常）で別のリンクとして作り、購入ボタンのURLを差し替える

> **要確認**：Stripe の資料では、段階制の価格は Payment Link で使えると読めますが、「数量の調整」と同時に使えるかは確認できていません。5 で金額が合わなければ、代案は「Claude が `/api/checkout` を作り、サーバーから決済画面を開く」方式です（コードの作業になります）。

## 3. 初年度の特典から通常価格へ切り替える（2027年）
- Payment Link は、特典の期間が終わったあとに自動で通常価格へ切り替えられません。
- そのため、**特典で買った契約は、最初の更新日の前に、価格Bから価格Aへ付け替える**必要があります（最も早い更新日は 2027-01 以降）。
- やり方は2つ。数が少ないうちは A が楽です。
  - A. Stripe の画面で、契約を1件ずつ開いて価格を付け替える
  - B. 数が増えたら、Claude に付け替えの手順（スクリプト）を作ってもらう
- **忘れないように**：2027-11 に、特典で買った契約の一覧を出して付け替える、という予定をカレンダーに入れる。
- 付け替え前に、お客さんに「来年から通常価格になります」と知らせる（購入ページと規約には書いてあります）。

## 4. サーバーが台数（`seats`）を返す（Claude の作業）
- `/api/activate` と `/api/verify` が、Stripe の契約の数量（quantity）を `seats` として返す。
- 返すようにすると、アプリは「使用中の車番」が契約台数を超えるとき、追加の車番を「休み」で登録する。
- **この変更は、購入リンクを数量つきに差し替えるのと同時に出す**（古い一律9,800円のリンクで買った契約は、数量が1台になり、車番が1台しか使えなくなるため）。
- 同時に直すもの：`config.js` の `priceLabel`（アプリ内の価格表示）、特商法の表、購入ページ。3つ（特商法・アプリ内・Stripe）が一致していること。

## 5. 本番での作業
1. 本番環境に切り替える（左上の表示を確認）
2. 1〜2 を本番で作り直す（テストのデータは引き継がれない）
3. `sk_live_…` を Vercel の環境変数 `STRIPE_SECRET_KEY` に登録して、再デプロイ（Production）
4. `config.js` の `stripe.checkoutUrl` を本番のリンクに差し替える
5. 自分のカードで実際に買って、有効化まで通す（その後、返金する）
6. カスタマーポータルの利用規約・プライバシーポリシーのURLを設定する（`宿題_手順書` の 1-5）
7. 神田さん用の無期限コード：クーポン（100%引き・期間「永久」）を作り、プロモーションコードを発行する
