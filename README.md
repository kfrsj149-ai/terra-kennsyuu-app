# TERRA 検収（terra-kennsyuu-app）

山林・製材工場での丸太検収に特化した、**オフラインファーストのPWA**です。
炎天下・重機騒音下・手袋着用の現場で、説明を読まずに使えることを最優先に設計しています。

---

## 1. すぐに動かす（開発者向け）

```bash
npm run dev     # http://localhost:5173 が立ち上がります
npm test        # JAS材積計算エンジンのテスト（12件）
npm run icons   # アイコンPNGを作り直すとき
```

ビルド作業は **一切不要** です。素のHTML/CSS/JavaScript（ESモジュール）だけで動くので、
`npm install` もいりません（開発サーバーとアイコン生成もNode標準機能のみで書いてあります）。
現場での起動速度を最優先した結果、この構成になっています。

## 2. 公開（Vercel）

このリポジトリをVercelに接続するだけで公開できます（フレームワークは「Other」＝静的サイト）。

公開後は、そのURLをスマホのブラウザで開き、
**Chrome の「ホーム画面に追加」／Safari の「共有」→「ホーム画面に追加」** を押せばインストール完了です。
アプリストアの審査は不要で、URLを共有するだけで配布できます。

## 3. 公開前に設定するもの

`src/js/config.js` の1ファイルだけを書き換えてください。

| 項目 | 説明 |
| --- | --- |
| `lemonSqueezy.checkoutUrl` | Lemon Squeezyの商品（年額サブスク）の購入ページURL |
| `lemonSqueezy.portalUrl` | 支払い・プラン管理ページのURL |
| `googleDrive.clientId` | Google CloudのOAuthクライアントID（未設定ならバックアップ機能は自動で無効表示） |
| `cacheVersion` / `sw.js` の `VERSION` | アプリを更新したら必ず上げる（古いキャッシュが残らないように） |

配色を変えたいときは `src/css/tokens.css` の `:root` だけを書き換えれば全画面に反映されます。
文言を変えたいときは `src/js/locales/<言語>.js` を書き換えます。

## 4. JAS材積計算について（最重要）

素材の日本農林規格（末口二乗法）どおりに計算します。

```
L < 6m : V = D² × L ÷ 10000                （補正なし。径級によりません）
L ≥ 6m : V = (D + (L′− 4)/2)² × L ÷ 10000  （長さ補正）
         L′ = 長さ(m)の整数部（1mに満たない端数を切り捨て）
         (L′− 4)/2 が負になる場合は 0 とする
```

- 計算は `src/js/jas.js` に集約。浮動小数点(Number)を一切使わず **BigInt（整数）** だけで行うため、
  何万本積み上げても1mm³の誤差も出ません
- 径級の刻みはJAS準拠で **14cm未満＝1cm刻み／14cm以上＝2cm刻み**
- 端数処理は `src/js/jas.js` の `ROUNDING_MODE` 1か所で切り替えられます
  （既定は小数第4位以下の**切り捨て**）

### 正確性の担保

`tests/table.test.js` が、長野県「林業積算基準 丸太材積表」の**全1578セル**
（長さ3.2〜12.8m × 直径4〜56cm）と計算結果を毎回突き合わせます。**不一致は0件**です。
表の値は小数第3位で四捨五入されているため、テストは切り捨て前の厳密値を四捨五入して比較し、
アプリ側の端数処理方針を変えても「計算式そのものの正しさ」を検証し続けます。

`tests/jas.test.js` には、かつて誤って径級補正 `(D-12)/2` を加えていた式に
戻っていないことを確認する回帰テストも入っています。

**コードを変更したら、必ず `npm test` が通ることを確認してから他の変更を進めてください。**

## 6. オフライン時の動き

現場での操作は**一切ブロックしません**。

- 入力した瞬間に端末内（IndexedDB）へ確定保存。通信の有無に関係なく必ず成功します
- 出力した伝票も全件ローカルに保存し、メニューの「伝票履歴」からいつでも再出力できます
- 通信が戻った時に、裏でGoogleドライブへ自動同期します（☁️＝同期待ち／✅＝同期済み）
- 未同期のデータは件数に関わらず保持し続けます。72時間以上圏外でも消えません
- サブスク確認はオンライン時のみ。最後に確認できてから30日間は圏外のままでも使えます
- **音声入力だけは通信が必要です。** 圏外ではボタンが自動的に無効になり、
  「壊れた」と誤解されないようタップ入力を促すメッセージが出ます

## 7. 将来の予定

音声入力のオフライン化（限定語彙のキーワードスポッティングモデルの内製）は
初版では着手しません。まずタップ入力中心で運用し、音声へのニーズの強さを見てから判断します。
利用者の明示的な同意に基づく音声データ収集の同意スイッチだけ、メニューに用意してあります。
